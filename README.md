# Геоастро — подготовка к экзамену по геодезической астрономии

Статический сайт (HTML + CSS + JS, без сборки и зависимостей) для подготовки к экзамену
«Геодезическая астрономия» (III курс, ГФ МИИГАиК). Содержит все 39 экзаменационных вопросов.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Карточки** | 162 карточки с переворотом. Оценка «не знаю / сомневаюсь / знаю» запускает интервальные повторения (система Лейтнера: 10 мин → 1 → 3 → 7 → 16 дней). Избранное, обратный режим, фильтр по блокам. |
| **Заучивание** | Раунды по 8 карточек с выбором ответа. Карточка считается освоенной после двух верных ответов подряд, ошибочная возвращается в раунд. |
| **Тест** | 89 теоретических вопросов с объяснениями + вопросы «к какому вопросу относится схема» + вопросы по карточкам. Разбор ошибок и «повторить ошибки». |
| **Подбор** | Игра на время: соедини термин и определение, рекорд сохраняется. |
| **Билеты** | Статус по каждому из 39 вопросов и имитация экзамена: случайный билет, 3 минуты на подготовку, проверка по краткому ответу. |
| **Конспект** | Полная методичка: теория, формулы (MathML) и 26 схем. |

Также: поиск по всему материалу (клавиша `/`), тёмная тема, горячие клавиши, экспорт/импорт прогресса.
Прогресс хранится в `localStorage` браузера.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (например, `geoastro`).
2. Загрузите в корень репозитория содержимое этой папки: `index.html`, папку `assets`, `.nojekyll`, `README.md`
   (через «Add file → Upload files» или `git push`).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/geoastro/`.

Локально сайт открывается двойным щелчком по `index.html` — сервер не нужен.

## Как добавить или исправить материал

Все данные лежат в `assets/data.js` (объект `window.DATA`):
- `cards` — карточки `{id, t: номер вопроса, f: лицевая сторона, b: оборот}`;
- `quiz` — тестовые вопросы `{id, t, q, o: [варианты], a: индекс верного, e: пояснение}`;
- `tickets` — 39 вопросов с кратким ответом, «запомни» и полным текстом.

Источник: Уралов С. С. «Курс геодезической астрономии» (М.: Недра, 1980).
